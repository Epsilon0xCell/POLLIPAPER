POLLIPAPER

POLLIPAPER is a Windows only desktop program written in Python with tkinter. It asks the Pollinations AI service for pictures, saves what comes back, and puts the result on the desktop through the Windows IDesktopWallpaper COM interface. It will not run on macOS or Linux, and this book says so on its front page, in the open.

Start: the repo on GitHub Open the cue book

Cue one: the prompt

Type a prompt into the text box, or fish an older one out of the history dropdown. The history remembers the most recent 20 prompts and keeps them in prompt_history.json. The typed words are percent encoded into the Pollinations request address.

Cue two: the performance controls

The Start button turns into Stop while the program runs. The Enhance tick box asks for improved wording, and that improved wording can be read back from the returned image EXIF data. The model picker defaults to flux, alongside flux realism, flux anime, flux 3d, any dark, and turbo, named in the program as flux, flux-realism, flux-anime, flux-3d, any-dark, and turbo. The change interval is set from the Options menu, with a floor of five minutes.

Cue three: how the picture sits

Wallpaper styles are named exactly as the program names them: center, tile, stretch, fit, fill at 1920 by 1080, and span at 3840 by 1080.

Cue four: weather from outside

With an OpenWeatherMap key supplied through the Options menu or the OPENWEATHER_API_KEY environment variable, the program can shape prompts from local weather or lay a weather panel over the picture. The panel controls: opacity from 0 to 255, position, background colour, an optional drop shadow, and temperature shown in Fahrenheit or Celsius after a metric fetch. The honest limits sit on this card too: the place is not choosable in the window, the code defaults to Rochester, US, and weather calls time out after 15 seconds.

Cue five: housekeeping at the back of the book

Pictures collect in a folder called POLLINATIONS_BACKGROUNDS. Only the five newest backgrounds and the single newest finished wallpaper are kept; older files are deleted. Settings persist in background_settings.json. Image generation retries up to five times with backoff. The install is python POLLIPAPER.py after installing requests, Pillow, comtypes, and pywin32:

pip install requests Pillow comtypes pywin32
python POLLIPAPER.py
